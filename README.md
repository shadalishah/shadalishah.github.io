# Shad Ali Shah Quarto Portfolio

## Local preview
Open the `.Rproj` file in RStudio, then use the **Terminal**, not the R Console:

```bash
quarto preview
```

Do not use RStudio's old **Build Website** button if it calls `rmarkdown::render_site()`.

## Render

```bash
quarto render
```

## Publish
Push this repository to GitHub and enable GitHub Pages through the included workflow. The exact `shadalishah.com` URL requires purchasing the domain and connecting its DNS records to GitHub Pages.

## Profile photo
The profile-photo block has been intentionally removed. No profile image is required.
